# ShiftReport
Una web app que permite a operadores y supervisores de planta industrial generar reportes de turno/semana de forma estructurada, con asistencia de AI para redacción, detección de anomalías y sugerencias. El usuario llena un formulario guiado (tareas, incidentes, métricas) y la AI genera un reporte profesional exportable a PDF y DOCX.
